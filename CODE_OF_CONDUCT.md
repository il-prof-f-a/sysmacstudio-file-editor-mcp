# Code of Conduct

The project aims to provide a respectful, useful space for users and contributors. Participation in issues, discussions, and pull requests is expected to be constructive and considerate.

Examples of unacceptable behavior include harassment, discrimination, personal attacks, deliberate disruption, publishing someone else's private information, and sharing confidential customer or workplace data without authorization.

Maintainers may edit or remove contributions that violate this policy and may restrict participation when needed to keep the project safe and useful.

## Reporting

For a conduct concern, use the contact method available on the [maintainer's GitHub profile](https://github.com/il-prof-f-a). If you cannot contact the maintainer privately, use the **Request a private contact** issue form; do not include sensitive details in the public issue.
