# Security Policy

## Supported versions

There are no tagged releases yet. Security fixes are made against the latest `main` branch. Once releases are published, this section will list supported versions.

## Reporting a vulnerability

Do not report a vulnerability in a public issue, discussion, or pull request, and do not attach a project archive, credentials, PLC source, or unsanitized runtime receipt.

When GitHub private vulnerability reporting is available for this repository, use **Security → Report a vulnerability**. If that option is unavailable, use the **Request a private contact** issue form and include no vulnerability details. The maintainer can then coordinate disclosure privately.

Please include the affected version or commit, the impact, a minimal reproduction that contains no customer data, and any mitigations you have identified. Do not test against a live PLC or a project you are not authorized to use.
